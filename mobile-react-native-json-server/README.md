# Mobile React Native JSON Server

This project is a simple JSON server setup for a mobile React Native application.

## Setup
1. Install dependencies:
    ```sh
    npm install
    ```

2. Build the project:
    ```sh
    npm run build
    ```

## Usage

1. Start the server:
    ```sh
    npm start
    ```

2. Serve the built project:
    ```sh
    npm run serve
    ```
